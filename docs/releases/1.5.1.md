## 本版改动

这一版有两块重点。一是服务端每次请求只发数据，卡片、行、说明文字都在浏览器里拼；上线实测，被免费计划 10 ms 掐掉的请求从约三成降到零。二是新增官方小助手，可以替玩家排建造、科技、冒险、打营寨、加点。另有拼图图集、登录防护等改动。

### 玩法

- **官方小助手**（GM 规则 `assistant.enabled` 设为 1 才出现）：独立页面，只在浏览器里运行，读的是页面已有的数据，像玩家点按钮一样发命令，不给服务器加负担。设置存在这台浏览器里，可以导出、导入。
  - 建造队列：不限长度，跨城池；能设资源保留线；失败时可选跳过、取消或卡住。
  - 科技队列：选好科技和目标等级，自动展开前置科技，按依赖顺序一级一级研究。
  - 冒险：可以排冒险队列，也可以设练级规则，按"最稳拿下里经验最高"给每位英雄挑任务。可以限定英雄范围、秘境、停止条件。
  - 营寨：按规则自动出兵。兵力用固定数，或按营寨守军乘系数；能设目标范围、阵型、停止条件。
  - 加点：按比例或分阶段自动加属性点。
- **拼图**：
  - 碎片改成有数量的库存，玩家在道具页自己兑换，可以一次兑一张，也可以批量。
  - 新增图集：拼成的图像相册一样一页一张，有翻页效果，记下首次拼成的日期。已下架、已停止掉落的图标"绝版"。
  - 拼图兑换得到的英雄不受英雄上限限制。
- **新手保护**只保护不被攻打，自己可以主动出击。GM 可以给指定玩家延长、重设或取消保护期。
- 宫殿 / 府衙增加外城名额的等级改为 3、7、10、15、20 级（以前是 1、5、10、15、20 级）。

### 界面

- 只在特定等级才给的加成，统一写成"当前 → 下一级"，并标出下一档（"★ 3 级：外城上限 +1"），完整档位表放在悬停提示里。建筑和科技都按这个写法。
- 兵营卡片写出训练加速；秘境每个任务下方写出最长用时。
- 碎片兑换按钮改为"兑换"和"批量兑换"；GM 可以给拼图写一段说明，显示在拼图下方。
- 地图、城池、英雄、军队、秘境、科技各页改为浏览器拼接显示，内容和以前一样，同步的数据量明显变小：
  - 秘境页每次同步从约 34 KB 降到约 0.1 KB；
  - 地图从约 12 KB 降到约 4.5 KB；
  - 英雄页从约 4.4 KB 降到约 1.6 KB。
- 科技页的数据只在变了时才发；"资源够不够"由浏览器判断，服务端照样校验。

### GM 与运维

- **登录与注册防护**：
  - 密码连续输错会锁定一段时间，分三种计数：同一用户名加同一 IP、同一用户名、同一 IP。阈值可在 GM 规则 `accounts.loginLimits` 里调。
  - 注册时邀请码错太多次，按 IP 锁定。
  - 失败满 3 次后，要先过 Cloudflare Turnstile 人机验证（可选，见升级须知）。
  - 免费的 WAF 限速规则怎么设，见 `docs/deployment.md` 5.5.1。
- **GM 命令**：给玩家发拼图碎片；设置新手保护。
- **服务端 CPU**：
  - 后台任务没活时不装配；
  - meta 版本号在构建时算好；
  - 地形按城池存一行，算产量不再读整张地图；
  - 到期事件一次预读；
  - 页面不变的数据只经 R2 下发一次，每次同步只发会变的数据，并带变动戳，没变就不发；
  - 按需取数走新的只读地址 `/api/data`。

### 修复

- 战报里的胜负结果在中文界面显示成英文（"victory"）。
- 秘境据点补满的记录只存在内存里，换实例后每次都要重新数一遍。

## 升级须知

- **新迁移** `0022`–`0028`（拼图库存、新手保护、拼图说明、登录失败计数、秘境据点状态、拼图首次兑换时间、城池地形）。
  - 部署在 Cloudflare 的：照常先 `pnpm db:migrate`，再 `pnpm run deploy`。部署后运行一次 `pnpm statics:refresh`，让静态数据按新格式重新生成。
  - Docker：拉新镜像重建即可。
- **人机验证（可选）**：要同时设公开的 `TURNSTILE_SITE_KEY` 和密钥 `TURNSTILE_SECRET` 才启用，步骤见 `docs/deployment.md` 第 5 节。不设也能用，只是没有这一层。
- **小助手默认关闭**：GM 在规则里把 `assistant.enabled` 设为 1，玩家页面上才会出现。
- **玩家要刷新页面**：前端改动较大，旧页面和新服务端的数据格式对不上，可能显示不全。刷新一次就好。
- **第三方插件作者**：几个往别的界面里加内容的钩子，改成"服务端只给数据、前端插件拼文字"：
  - `heroes.addCardLines` → `heroes.addCardData`；
  - `buildings.addEffectLines` → `buildings.addEffects`；
  - `worldMap.addLayer` 要传图层 id，并且只返回数据；
  - 兵种的建筑门槛改用 `troops.requireBuilding`。

  文字由前端插件在扩展点（`defineClientPart`）里拼。用到这些钩子的插件需要照 `docs/plugin-guide.md` 修改。
