## 本版改动

### 玩法

- 掉落改为"按价值抽"：每次掉落给一个最低总价值，按权重从奖励池里抽，直到抽到的东西加起来够这个价值；越稀有的东西越值钱。每个池带一格"空手"，最低值小时常常空手，越大越难空手。秘境每个任务一个奖励池；流寇也用这套算法；攻打 NPC 城池、攻打玩家也有了奖励池（默认是空的，留给以后的内容插件）。
- 秘境掉落重新调过：第一个任务每组平均约 0.8 件（约四分之一空手），最后一个任务约 2–2.6 件；秘境页显示每个任务的平均件数和空手概率。
- 幸运更有用：魅力 100 的英雄在秘境里的平均掉落是没有魅力的 3 倍。
- 秘境更难也更多样：每个秘境 4–6 个任务，各有名字和难度；攻击会落空；出发前显示"手到擒来 / 可以一试 / 小有凶险 / 凶多吉少"四档预计。
- 秘境掉落元宝；新增 +100 经验的"行军札记"，《武经》残卷与《武经总要》降低掉率、提高售价，土地契掉率降低，招贤令掉率提高。
- 科技：资源科技最高 20 级，每级增产 2%，在 1 / 3 / 7 级分别解锁对应建筑的 6 / 10 / 15 级以上；新增盐铁、市舶（金币）、草市、牧政、林政、开山、坑冶、坎儿井（各类地形）、车营（辅助兵种速度）、墨守（守城器械强度）。
- 驻守研究所的英雄也降低研究费用（与减时间分开计算）。
- 仓库、隐藏仓库容量大幅提高（约 5 倍，高等级更陡）；守城器械的维持开销按种类换成不同资源。
- 城墙可以排队：工事和器械可以连续下单，排队的可以取消并全额返还。兵营的训练计划每条队列最多排 5 个（可由 GM 调整）。
- 新道具：更名帖（英雄改名）、易号诏（城池再次改名；第一次命名仍免费）、听曲楼请帖（有望多一名候选人，第 4 次必成）、酒旗新挂 / 书院招贤榜（立即换一批候选人）、迁建令 / 易地令（同一城区内移动或互换建筑）。

### 界面

- 购买成功后整屏提示，点"好的"才能继续操作；取消训练计划也要二次确认。
- 城池页左栏新增生产表：每种资源的库存、净增长、原始产出、加成、消耗（鼠标停在加成 / 消耗上看来源），爆仓只在净增长一列显示。
- 各种加成按来源显示：研究所里的研究速度、用时和费用，建造用时，训练用时，维持开销；建造队列、外城上限、英雄上限、库存上限在鼠标悬停时列出来源。
- 训练数量框显示"最多 N"（按资源、额度和单批上限）。
- 英雄加点改为六行的表格（合计、初始、天赋、加成、已加点、本次加点）；英雄页显示"英雄 x / 上限"。
- 科技卡片写"已解锁：农田 6 级以上"和下一个节点；研究受阻的原因分清"本城正在研究这一项 / 其他科技 / 在别的城池研究"。
- 资源栏到上限时显示"爆仓"；表单在页面隐藏时不再刷新，操作后的等待明显缩短。

### GM 与运维

- 新规则：`loot.rules`（含基准权重 `baseWeight`、空手格 `empty`）、`loot.weights`（掉落；可以按组写，`realms` 对所有秘境任务生效）、`queues.maxWaiting`（每条队列可排队数）、`npc-camps.lootValue`、`pvp.lootValue`、`realms.rules.outlook` / `miss`、`starter-siege.wallSpeed` 等。
- Docker 新选项 `-e USAGE_LOG=on`：每 4 小时在日志里打一行用量（请求数、D1 读写行数、库大小、CPU 估计，以及占 Cloudflare 免费额度的比例），用来估算上 Cloudflare 的用量；见 deployment.md 第 6 节。只在本地 / Docker 开了选项时才记录，正式部署不受影响。
- 数据库新增 3 个迁移：`0002_queues.sql`、`0003_items_pity.sql`、`0004_heroes_refresh.sql`。

## 升级须知

- **先迁移再部署**：`pnpm db:migrate`（Docker 见 deployment.md 的升级步骤）。进行中的训练和城墙建造会在第一次用到那座城时自动转到新的队列，按原来的时间完成；道具的保底次数在迁移时拷到新表。
- **以下 GM 规则改了名字或格式**，旧的覆盖值会在 GM 规则页报错并被忽略（游戏照常运行），请按新格式重新设置：
  - `realms.dropWeights` → `loot.weights`（按奖励池写，如 `{ "realms": { "scrap-metal": 0 } }`）；
  - `realms.rules` 里的 `dropTiers` → `loot.rules.tiers`；
  - `bandits.rules` 里的 `drops` 改为 `{ chance, value, perLevel }`；
  - `starter-defense.hiddenStore` 改为 `{ perLevel, from1, factor1, from2, factor2 }`。
- 视图 `realms.overview` 的任务字段 `dropCounts` 换成了 `loot`；自己写的前端插件如果读了它，需要改。第三方插件定义秘境时要写 `taskCount`（任务数）。
