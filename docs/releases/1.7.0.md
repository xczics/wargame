## 本版改动

这一版有两个新玩法：英雄转世和商路开拓。

### 玩法

- **英雄转世**：90 级以上的英雄可以用转世丹转世，最多九转。
  - **转世时**：回到 1 级，经验清零；已分配的自由点并入天生属性，每转再给一笔自由点，天赋另加 2–6 点，补在最低的一维上。
  - **成功率**：第 N 转的成功率是 1/N，失败不会忘记已试过的次数，第 2N+1 次必成。
  - **英雄卡**：用五星显示转数，一到八转每转半颗，九转是一整颗金星。
  - **转世丹从哪来**：聚宝阁卖 1,500 元宝；第 5 个秘境起有机会掉，越难的秘境、越靠后的任务越容易掉；商路第四章的商人每天卖一颗，1,200 元宝。
- **商路开拓**：新页签"商路"。默认三条商路：丝绸之路、茶马古道、海上航线，后一条的开局难度大约是前一条的中段。每条四章，每章九个地点，上一章的首领是下一章唯一的入口。
  - **组队出发**：最多三名英雄，每人带一类兵，带兵上限按等级、统率和魅力算；可以带辎重队和军医。出发时按预算的小时数一次付清部队维持，换成体力。走路、打仗都花体力，走已经打通的路只要三分之一。体力用完或到时间回城，也可以随时召回，预算不退。
  - **地图**：古地图画风。只看得见已开拓地点旁边的地方，其余是雾。走过的地方会讲一段故事，三条路的故事连成一条主线。
  - **战斗**：各路兵团轮流互砍，回放里能看到像素小兵一刀一刀地打，可以跳过和重播。
    - 每一刀约有十分之一会落空，伤害有 ±15% 的浮动。
    - 兵种相克和攻城、野战用同一套规则：部队那部分攻击或防御 ×3，英雄和科技的相克加成照样生效。
    - 英雄的谋略越高，越会挑被自己克制的敌军下手；谋略低的会乱砍。组队表单里写着每名英雄的"识破"率。
  - **敌将**：后面的敌军有将领带队，像不同阶段的玩家养出来的英雄：有名有姓，按酒馆招募的规则抽属性，自由点按常见的路数分配（先锋、统帅、猛将、谋将、军师）。越往后越强，开头的普通敌军群龙无首。
  - **打赢之后**：地点就此打通，不再刷新；出战英雄得经验，偶尔顿悟，多得自由点；按章节掉落资源令状、加速、老兵召唤令、兵书、破境石、转世丹、套装。
  - **商人**：每天四样货，用元宝买聚宝阁买不到的东西：老兵召唤令、24 小时加速、部分套装。
  - **难度**：每个成长阶段大致对应一章。普通敌营轻松，首领要全队上阵、损失两成左右；海路终章要靠装备、科技或转世，满级不穿装备打不过。
- **开拓据点与互市**：外城可以建开拓据点（每城一座）。商路上的关键节点打通后会开通商单，每天能按资源价值用一种资源换另一种，有损耗。打通的地方越多损耗越低；据点等级越高，交易越快。
- **新道具**：
  - 六种老兵召唤令：在训练建筑里使用，直接得到 5、6 级老兵；
  - 三种 24 小时加速：只在商路商人处有卖；
  - 转世丹。

- **营寨守将、流寇头目**：和商路敌将一样，换成了像玩家养出来的真人（有属性、有加点路数），加成按玩家英雄的公式算；各级的强度按以前配好，大致不变，多了一点每路固定值。

### 界面

- 用户菜单：顶栏只留"用户名 ▾"，点开是声望、GM 入口、语言、修改密码、退出，电脑和手机一样；语言选择从底栏挪了进来，名字只写语言本身（"中文""English"）。

### GM 与运维

- 新 GM 规则：
  - 转世 `rebirth.rules`；
  - 商路 `trade-routes.rules` / `capAttrs` / `aimAttrs` / `combat` / `epiphany` / `budgets` / `trade` / `merchant`；
  - 另加商路 `trade-routes.custom`：和内容同一格式的三张表，可以写敌将。
- GM 后台“操作”页可以给玩家重置密码：生成只显示一次的临时密码，原密码和已登录的设备立即失效，玩家登录后要先改密码；写审计日志。
- 人机验证被拒时，Worker 日志里会写 Cloudflare 给的原因（密钥不对、凭证过期等）。
- 新脚本 `scripts/reset-password.mjs <用户名>`：不进 GM 后台也能给玩家设临时密码（例如 GM 自己的密码之外的应急），见部署文档"常见问题"。

### 修复

- 商路掉落的装备在结算里显示英文名。

## 升级须知

- 有两个新的数据库迁移：`0037_rebirth`（英雄转数）和 `0038_trade_routes`（商路的进度、开拓队、交易、商人）。部署前先执行迁移（`pnpm db:migrate`）；Docker 镜像启动时会自动执行。
- GM 规则 `npc-camps.levels` 里守将的五个字段（人数、攻 / 防 / 血 / 伤亡 %）换成一个 `generals`（每名守将一个配方，如 `tavern/3/8`）；之前改过这几个字段的覆盖值需要按新写法重填。流寇的等级表同样换了列（内容表 `levels.csv`）。
- 新插件：`rebirth`、`trade-routes`、`npc-heroes`（NPC 英雄生成器）、`starter-trade-routes`（三条商路的内容）。
- 第三方插件：
  - 战斗服务新增：
    - `BattleSide.heroes`：直接指明领兵的英雄；
    - `BattleSide.generals`：没有英雄档案的 NPC 将领；
    - `laneNumbers` / `counterBoost` / `casualtyFactor`：一路兵的属性、相克倍数、伤亡系数，别的战斗也请用它们；
    - `finalLosses`；
    - `addGenerals`：给没有英雄的一方（NPC）补上将领。
  - 英雄服务新增 `reincarnate`、`freePerLevel`；装备内容服务新增 `roll`；NPC 英雄配方用 `npcHeroes.addRecipe`。
