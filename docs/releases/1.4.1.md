## 本版改动

这一版按 1.4.0 的测试反馈调整：性能、数值、一批 bug 和显示问题，以及几个新功能。数值改动上线时，升级之前积累的产出仍按旧数值结算。

### 玩法

- **伤害公式**：一路受到的伤害改为「对方攻击² ÷（对方攻击 + 我方防御）」。以前兵力占优的一方几乎不死兵，现在双方都有伤亡，占优一方伤得少。势均力敌时伤亡明显上升；GM 可以用新规则「伤害系数」整体调低。
- **钱庄**：前十级产量曲线比线性略陡，10 级产量是原来的 3 倍；11 级以后的增长倍率不变。
- **军队维持费**：货币部分提高到原来的 3 倍（占 15% → 45%），粮食相应减少，总量不变。
- **资源要塞**：同样的城防器械，防御是其他城池的 3 倍；城防维护减半，并且不再消耗货币（这部分分摊给其他资源）。
- **流寇保护道具**：巡检文书、团练令、招安告示、剿匪诏，分别在 24 / 48 / 72 / 144 小时内不生成流寇。可在聚宝阁「防护」类购买；保护期内再用一张会顺延。
- **拼图奖励「永久防御」**：兑换时选自己的一座城池，该城每路防御永久增加；这部分不受任何百分比加成影响，最后才加上。
- **GM 群发邮件可以带附件**（资源、道具、元宝等），玩家在邮件里领取，每人每封一次。

### 界面

- **地图格子**：选中格子后点「操作」才展开派遣、建城、攻打等表单；展开后换格子保持展开。
- **出兵类表单**（建城、派遣、攻打、运输）：每个格子都按所选出发城池显示「最多 N」。遣散部队、建造城防器械也有上限提示。
- **装备存放列表**：可以按颜色、套装、部位筛选。
- **不透明科技面板**：只列已经获得的加成，每项一行合计，不再按分组列出。
- **道具快捷按钮**：放到了用得上的地方，比如研究加速在研究所和科技页，建造加速在城池页，经验书在英雄页。
- **邮件**：翻页明显变快；有附件的邮件带 🎁 标记。
- **站点图标**：不再 404；GM 可以在新的「个性化」页签换图标、上传自己的图标、改站点标题。
- **手机上的 GM 后台**：页签可以左右滑动，不再挤成一个字一行。

### GM 与运维

- GM 后台新增「不透明科技」页签：圆环分组编辑，以及每段包含哪些维度（按代号）、给什么加成。
- 新增 GM 表单「加速研究」。
- 建筑的产量和曲线现在也是 GM 规则 `buildings.rules` 的字段，可以按建筑调整。
- 性能：
  - 空闲时的定时任务不再每小时扫一遍全部城区。在 1.4 以前开的老世界里，原来每分钟约 450 行读取，现在只有几行。
  - 地图页读表减少约三分之二。
  - 状态接口不再接受「不指定视图就算全部」的请求。
- 用量日志：每个响应带 `x-usage-rows`（这次请求读写了几行），方便逐页检查读表量。
- **升级时先按旧规则结算**：每个版本第一次运行时，把所有规则的生效值存一份快照（放在 R2）。升级后，每座城池第一次被用到时，升级之前积累的产出按旧规则补算。这只覆盖写成规则的数值，伤害公式这类代码改动不在其中。

### 修复

- 手机通过局域网地址访问时，GM 后台点「新建拼图」没有反应。
- 战报里出现 `grade:crushing`、`attack` 这类原文，行军列表里出现 `victory · npc-camps.…`。
- 城防工事在已有一级排队时，再下单偶尔报「资源不足」（卡片显示的是下一级的费用，实际收的是更高一级的）。
- 秘境里「每组掉落价值」都显示为 0。
- 带兵种的相克加成以前对所有兵种生效，现在只对该兵种生效（1.4.0 已修，这里补记）。

## 升级须知

- 新迁移 `0014`、`0016`–`0019`。部署在 Cloudflare 的照常先 `pnpm db:migrate` 再部署；Docker 拉新镜像重建即可。
- 「升级时按旧规则结算」需要 R2 桶 `FILES`（1.4.0 起就需要）。从 1.4.0 升上来时，1.4.0 的旧数值已内置在新版本里。
- 伤害公式变了，同样的兵力打起来伤亡更大。如果觉得太血腥，在 GM 后台调低规则 `battle.damageFactor`（默认 1）。
- GM 群发改为一行存储：以前群发的邮件照常显示；新的群发只送达发送时已注册的账号。
