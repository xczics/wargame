# 插件清单

> 2026-10-24 按 `src/plugins/*/index.ts` 整理（id、依赖、提供的服务以代码为准）。怎么写插件见 [plugin-guide.md](plugin-guide.md)；扩展点的详细说明在各插件 `index.ts` 开头的注释和导出的接口里。

共 57 个后端插件，都在 `src/plugins.ts` 里注册；内核按 `dependsOn` 排序装配。

## 前端插件

`web/plugins/` 下 35 个，在 `web/plugins.ts` 里注册（第三方的在 `extensions/<id>/client.ts`，自动发现）：外壳（auth、settlement、resource-bar、forms）、通用控件 widgets（`web/widgets/` 里的 `ui.*`）、邮箱 mail、GM 后台 gm-panel、小助手 assistant，其余按系统各一个（与同名的服务端插件对应），放前端视图（数据视图 + 静态视图拼成控件数据）、扩展点部件和少数专门的组件。框架自己的文字在 `web/core/messages.ts`。

建筑卡片上的说明措辞：`starter-defense`（城墙防御、藏兵窖保护量）、`starter-siege`（城墙加快城防建造）、`starter-army`（兵营训练加速），双清观的在 `opaque-research`；都在 buildings 前端视图的扩展点 `buildings.effects` 上登记措辞（`defineClientPart`；服务端 `buildings.addEffects` 只发数字）。
