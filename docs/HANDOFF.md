- **K7a. 声望的产生和消耗**
  - 所有消耗（无论何种资源）按"资源值"累计：每 1000 资源值 = +1 声望（公式可调）。
  - 被打败赔声望：战斗中失去的资源 × 0.5 换算成声望损失。
  - 击败流寇得声望：敌方的报废部队换算成"如果训练需要的资源" × 0.3 换算成声望增加。
  - 设计详见 gameplay.md 附加章节"声望与流寇系统"。

- **K7b. 流寇的生成和等级**
  - 根据声望等级（每 5 点或每 10 点一级）和**地形分片的组成**，定期生成流寇（频率和流寇数量由声望成长周期决定）。
  - 声望快速增长的阶段（0–20）频率更高；之后稳定。
  - 流寇按兵种和等级多样化，低等级无英雄，高等级有英雄带队。

- **K7c. 流寇英雄**
  - 低级流寇无英雄；高级流寇有 1–N 个英雄。
  - 英雄有"有名有姓"的设定（虚构的武将名、小 story）；NPC 的带队英雄也用同一套（参考 5.5）。

- **K7d. 流寇的碎片存储**

- **K7e. 流寇出现判定**

  - 计划：
    - 初始 0 个外城。
    - 科技树 3 个关键科技节点（例如"城市规划""都市建设""都市管理"），各 +1。
    - 声望路线 5 个关键节点（声望等级 5、10、15、20、25 对应），各 +1。
    - 特定道具"外城许可"（见 H2、K6）：有望 +1，成功率随已有额外指标降低（例如 0 个 80%、1 个 60%、2 个 40%、3 个 20%、4 个 10%、5 个以上 0%）；即最多科技 +3、声望 +5、道具 +5、总 20。
    - 迁移 `0036_settlements_exterior_cap.sql`；GM 规则 `settlements.exteriorLimit` 和道具成功率。
