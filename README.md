# Wargame

## 这是什么

一款以中国中世纪（宋、明一类）为背景的放置类（idle）网页策略游戏：经营城池、训练部队、招募英雄、研究科技，在一张 1024×1024、首尾相接的地图上扩张和征战。离线时城池照常生产，回来时自动结算。

它也是一个**"一切皆插件"**的游戏框架：内核只负责装配和执行，资源、建筑、兵种、战斗、账号、GM 后台乃至界面摆放和中文文案，都由插件提供；第三方不改官方代码也能加入新玩法。

- 运行在 Cloudflare 上：Workers（后端）+ D1（全部数据）+ Static Assets（前端），一个仓库、一次部署。
- 技术栈：TypeScript、Vue 3、Vite、Vitest，包管理用 pnpm。
- 只有一个由部署者指定的超级管理员（GM）。玩家凭 GM 生成的邀请码注册；GM 可以在后台实时调整游戏规则、查看和操作任意玩家，所有操作都有审计日志。

## 部署

本地跑起来：

```sh
pnpm install
cp .dev.vars.example .dev.vars   # 本地 GM 账号
pnpm dev                          # http://localhost:5173
```

部署到自己的 Cloudflare 账号：创建 D1 数据库并写进 `wrangler.jsonc`，`pnpm db:migrate` 建表，用 `wrangler secret put` 设置 `GM_USERNAME` / `GM_PASSWORD`，再 `pnpm run deploy`。

完整步骤（环境要求、本地数据的备份与重置、地图生成与导入、上线流程、费用与限制、常见问题）见 **[部署与运维](docs/deployment.md)**。

## 玩法

- **城池**：内城加若干外城组成一座城，外城建资源建筑（石头、木头、粮食、金属、货币），内城建仓库、兵营、研究所等；还能建分城、资源要塞、军事要塞。所在地形影响产出。
- **部队与战斗**：步、弓、骑三系各 6 级，彼此相克；战斗分五路，按赢下的路数定胜负，可以掠夺；幸存者在战斗中晋升。城墙和守城器械帮助防守。
- **英雄**：在酒馆、书院、听曲楼招募，有六维属性和天赋；可以带兵、守城、内政、研究，或去秘境冒险获取经验、装备和道具。
- **科技**：内政、军事两门类、四阶的科技树，解锁建筑等级和各种加成。
- **声望与流寇**：花费资源积累声望、升官职；声望越高，流寇来得越勤、越强，要留足守军。
- **其他**：NPC 据点与要塞、玩家之间的攻打、邮件战报、元宝商城与道具。

所有数值都可以由 GM 实时调整。完整设计见 **[玩法设计文档](docs/design/gameplay.md)**，界面布局见 [design/ui.md](docs/design/ui.md)。

## 开发与贡献

```sh
pnpm dev      # 前端 + Worker 同一个开发服务器，热更新
pnpm check    # 类型检查 + 格式检查 + 全部测试；通过才算完成
```

- **先读约定**：[AGENTS.md](AGENTS.md)（插件边界、数据与规则、引擎语义、测试要求）。核心几条：内核不含玩法；一个插件只管一个系统，插件之间只通过服务通信；数值放在插件的 `data/*.csv` 并通过 GM 规则暴露；表结构只能新增迁移。
- **写插件**：[插件开发指南](docs/plugin-guide.md)（配可运行的示例 `examples/watchtower/`）和 [插件清单](docs/plugin_architecture_reference.md)。
- **架构与开发步骤**：[开发文档](docs/development.md)；规划中的架构在 [design/architecture.md](docs/design/architecture.md)；当前状态与待办在 [HANDOFF.md](docs/HANDOFF.md)；改动记录在 [changelogs/](docs/changelogs/)。
- 贡献的代码按本项目的许可证（GPL-3.0）发布；提交前请确保 `pnpm check` 通过，新玩法同时更新设计文档。
